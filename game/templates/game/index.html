projeto acadêmico // python + django

Um jogo de advinhação simples, pensado para ser lido tanto quanto jogado.

Esse projeto nasceu de um trabalho de apresentação na faculdade. O desafio era escolher algo pequeno o bastante para explicar em poucos minutos, mas construído com uma estrutura organizada o suficiente para servir de exemplo. O jogo em si é direto: o computador escolhe um número entre 1 e 10 e o jogador tenta adivinhar. A maior dificuldade que presenciei neste projeto foi a conversão do framework Flask para o Django, pois já sabia utilizar o Flask, porém o Django ainda é novo para mim.

A versão original rodava inteira no terminal, com input() e cores via ANSI, e salvava a pontuação num banco MySQL à parte. Esta versão em Django usa o mesmo raciocínio — só que cada palpite chega como uma requisição, e o estado da partida fica na sessão em vez de numa variável local.

game // interativo

Advinhe o Número

O computador escolhe, em segredo, um número entre 1 e 10. A cada palpite errado, o jogo avisa se o número secreto é maior ou menor que o valor digitado — e conta quantas tentativas foram necessárias até o acerto.
Cada envio abaixo recarrega a página: o palpite vai para o servidor, o Django decide a resposta e guarda o resultado na sessão. Não há JavaScript decidindo o jogo — só um formulário normal.
01

Intervalo fixo

O número secreto está sempre entre 1 e 10.

02

Dica a cada rodada

O servidor informa se o palpite foi maior ou menor que o número certo.

03

Contagem de tentativas

Cada partida guarda, na sessão, quantos palpites foram usados até o acerto.

04

Pontuação salva

Ao vencer, o nome e o número de tentativas viram um registro no banco.
